
# Figures

This directory contains the figures used in the README and generated during the analysis of urban tree phenology in Barcelona.

| Figure | Description |
|---------|-------------|
| `thermal_zonation.png` | Annual mean land surface temperature (LST) classified into four thermal zones (Zone 1–Zone 4) using k-means clustering. |
| `evi_dynamics.png` | Seasonal EVI dynamics for the three tree species in the coolest (Zone 1) and warmest (Zone 4) thermal zones based on double logistic curve fitting. |
| `phenology_metrics.png` | Comparison of land surface phenology (LSP) metrics, including Start of Season (SOS), Peak of Season (POS), End of Season (EOS), and Growing Season Length (GSL), between thermal zones. |
| `sensitivity_curve.png` | Sensitivity analysis of phenological metrics using different dynamic threshold values. |
| `methodology_workflow.png` | Overview of the complete methodological workflow, from satellite image preprocessing to phenological analysis and statistical evaluation. |

## Notes

- All figures were produced using Python.
- Figures are publication-quality and correspond to the analyses presented in the associated manuscript.
- The methodology workflow summarizes the complete processing pipeline implemented in this repository.
